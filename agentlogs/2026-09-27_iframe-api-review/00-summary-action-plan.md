# PayTR IFrame API: Executive Summary & Action Plan

## Pipeline Overview
This report suite was generated by the PayTR Analysis Pipeline (BA → Architect → Engineer) on 2026-09-27. The Business Analyst audited the current implementation against the official PayTR IFrame API documentation (`STEP 1` and `STEP 2`), uncovering critical installment mapping bugs. The Architect reviewed the system's resilience and design abstractions. Finally, the Engineer audited the codebase, rejecting over-engineered resilience proposals in favor of pragmatic, targeted bug fixes that align with the NuGet package's lightweight design philosophy.

## Critical Issues (P0) — Fix Immediately
1. **Broken Installment Logic**
   * **File:** `src/Ali.PayTr.Core/Clients/PayTrClient.cs`
   * **Action Required:** Fix inverted `no_installment` mapping and invalid `max_installment` values to prevent PayTR API rejections and checkout UI failures.
2. **Webhook Response Content-Type**
   * **File:** `src/Ali.PayTr.AspNetCore/Endpoints/PayTrNotificationEndpoint.cs`
   * **Action Required:** Change `Results.Ok("OK")` to `Results.Text("OK", "text/plain")` to prevent JSON formatters from returning `"OK"` (with quotes) and breaking PayTR's webhook loop.

## High Priority (P1) — Fix Before Next Release
1. **Basket JSON Formatting**
   * **File:** `src/Ali.PayTr.Core/Clients/PayTrClient.cs`
   * **Action Required:** Convert decimal prices to strictly formatted strings (`ToString("0.00", CultureInfo.InvariantCulture)`) before JSON serialization to match PayTR's undocumented expectations.
2. **Missing Webhook Parameter**
   * **File:** `src/Ali.PayTr.AspNetCore/Endpoints/PayTrNotificationEndpoint.cs`
   * **Action Required:** Read the `payment_amount` parameter from the incoming POST form, which is currently ignored.

## Medium Priority (P2) — Plan for Near-Term
1. **Configurable Timeout**
   * **File:** `PayTrOptions.cs`, `PayTrCreatePaymentRequest.cs`, `PayTrClient.cs`
   * **Action Required:** Replace the hardcoded `30` minute timeout with a configurable property.
2. **Explicit Hash Salt Concatenation**
   * **File:** `PayTrHashService.cs`
   * **Action Required:** Remove implicit `merchant_salt` appending from the hash service. Force the caller to concatenate the salt to make the dependency obvious and prevent future bugs.

## Low Priority (P3) — Backlog
1. **Webhook Idempotency Race Condition**
   * **File:** `PayTrNotificationProcessor.cs`
   * **Action Required:** Implement optimistic concurrency (EF Core RowVersion) on `PayTrOrder` to handle duplicate, perfectly simultaneous webhooks.
