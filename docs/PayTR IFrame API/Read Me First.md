# **Integration consists of 2 steps:** 

**STEP 1** - Display the payment form in an iFrame: A server-side request to the API is necessary to obtain iframe_token. Payment form can then be opened inside an iFrame HTML TAG using this token. 

**STEP 2** - Create the Callback URL to Receive Payment Results: Callback URL is the URL of a page on your website where the PayTR system will POST payment results.
